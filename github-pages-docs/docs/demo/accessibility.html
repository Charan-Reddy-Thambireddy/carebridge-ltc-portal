Accessibility statement

CareBridge is designed so that older adults, people with disabilities, caregivers and agency staff can use it independently, with or without assistive technology.

Conformance target

This site aims to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 at Level AA, which is the standard referenced by the Section 508 refresh and the U.S. Department of Justice ADA Title II rule for state and local government websites.

What you can do on this site

  • Use every feature with a keyboard alone
  • Zoom text up to 400% without content being cut off or needing to scroll in two directions
  • Use a screen reader such as JAWS, NVDA or VoiceOver, including announcements when results load or a decision is saved
  • Use Windows high contrast (forced colors) or turn off animation in your operating system
  • Request notices in large print, Braille, audio or an accessible electronic format

How we test

  • Automated: axe-core scans of every page in the continuous integration pipeline. The build fails on any WCAG 2.1 A or AA violation.
  • Manual keyboard testing: focus order, visible focus, no keyboard traps, dialog focus management
  • Screen readers: JAWS and NVDA with Chrome and Firefox on Windows, VoiceOver with Safari on macOS and iOS
  • Zoom and reflow at 200% and 400%, and a 320 CSS pixel wide viewport
  • Color contrast checks of every design token pairing

Known limitations

This is a demonstration project. Staff sign-in, document upload and printed notices are not implemented. The API documentation page (Swagger UI) is a third-party tool provided only for developers and is not covered by this statement.

Feedback

If you find a barrier on this site, please open an issue in the project repository and describe the page, what you were trying to do and the assistive technology you were using.
