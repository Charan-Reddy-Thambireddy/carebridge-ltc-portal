Programs

  • Medicaid long-term care

    Help paying for care in a nursing facility for people who need help with daily activities and have limited income and assets.

  • Home and community-based services

    Support that helps people stay in their own homes: personal care, home-delivered meals, adult day health and respite for caregivers.

  • Medicare Savings Program

    Help paying Medicare Part A and Part B premiums, deductibles, coinsurance and copayments.

Built accessibility-first

Every page targets WCAG 2.1 Level AA and Section 508, and is tested with axe-core, keyboard-only use and screen readers.

  • Skip link, landmarks and a logical heading structure on every page
  • Forms with visible labels, hints, an error summary and inline messages linked to each field
  • Sortable data table with aria-sort, a caption and announced result counts
  • Keyboard-operable tabs and a modal dialog that traps and returns focus
  • Color contrast of at least 4.5:1, visible focus, 44px targets, reflow at 320px, reduced-motion and high-contrast support
